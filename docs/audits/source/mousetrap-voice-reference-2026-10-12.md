# Mouse Trap speech I/O reference capture — 2026-10-12

> **Historical first-pass capture.** The 3,600-frame file hash and counts below belong to the original run and remain useful as preserved evidence. The recorder's RIOT filter then accepted only offsets 0–3 in each 32-byte window, although the pinned MOS6532 map mirrors valid PA/DDRA/PB/DDRB registers at offsets 8–11, 16–19 and 24–27. The active-low field schedule was not accompanied by a screenshot proving entry into gameplay. See the corrected bounded capture and its input/screen findings in [mousetrap-native-phrases-2026-10-12.md](mousetrap-native-phrases-2026-10-12.md); conclusions about missing game-issued phrases should be based on that audit.

This capture observes the Mouse Trap game with the pinned local MAME executable and uses only its normal game inputs. The Lua tap records ordered, timed reads and writes from the voice Z80 I/O bus, the sound 6502's RIOT window, and the game's sound communication window. It does not alter CPU memory, ROM, reset lines, or speech commands.

## Source basis

The pinned MAME source identifies the digital voice CPU as a Z80 with a 16 KiB ROM and an 8-bit I/O map. In `mtrap_sound_device::voiceio_w`, ports with A4 low drive MC3417 digit input from D0, and ports with A5 low drive RIOT PB0 (busy). Reads with A7 low return command bits from the RIOT PA data, permuted by `bitswap(m_cvsd_data,3,0,2,1)`; reads with A6 low return the CVSD clock in bit 7. The sound 6502 writes the RIOT PA data through the mapped 6532 window; PA bit 4 controls release/reset of the voice Z80. These details are in `simulation/reference_sources/exidysound.cpp` and `simulation/reference_sources/exidy.cpp`.

The recorder is [mousetrap_voice_capture.lua](../../../tools/reference_cases/mousetrap_voice_capture.lua). Its CSV stores event kind, bus, emulated frame/time, issuing PC, address, data, and mask. It records Z80 command/status reads and digit/busy writes, plus clock-only reads (A7=1, A6=0). Its input schedule applies coin at frames 420–445, one-player start at 480–510, right at 600–720, dog at 750–780, colored buttons at 900–1230, then repeats right/dog later. All controls use MAME's declared game fields, after the sound RIOT setup at frame 322. [mousetrap_voice_summary.py](../../../tools/reference_cases/mousetrap_voice_summary.py) streams the CSV and reports event counts, clock samples, resolved RIOT output callbacks, and an abbreviated trace.

The completed CSV has 4,081,211 ordered events (173,553,670 bytes, SHA-256 `3D23B8FB1ABC46F3461EA60BA53B8736130958E6D8C06FEE8736B5AB7DEB8445`): 3,152,457 voice-Z80 reads, 928,482 voice-Z80 writes, 268 main-CPU sound-window writes, and four saved audio-6502 RIOT register writes. The Z80 read trace includes 2,223,977 clock-only reads at `BF`; bit 7 samples both states (`FF` high and `7F` low). It also contains 928,480 A7-low command/status reads at `7F`, all returning `FF`. MAME's voice handler accepts 928,480 writes as CVSD digit writes (A4 low) and two as RIOT PB0 busy writes (A5 low). Audio RIOT writes at frame 322 were `DDRA=1F`, `ORA=EF`, and `ORA=FF` at 5.371746792, 5.371760202, and 5.371779199 seconds. Applying the 6532 output-latch rule `(ORA & DDRA) | ~DDRA` yields callback values `E0`, `EF`, then `FF`; bit 4 is released only on the last update. A fourth write configures DDRB. The CSV holds per-bit digit data and timed command/status and clock reads for replay.

The later coin/start/movement/button inputs produced main-CPU sound-window activity, including bursts at frames 1,463, 1,465, 1,977, and later, but no additional RIOT ORA/DDRA updates after the frame 322 initialization. Z80 digit writes continue through the capture, but their audio content has not been classified as words or phrases. This capture therefore supplies the native serial stream and clock samples, not evidence of multiple game-triggered speech commands. The MAME trace has not been compared against RTL here, so it is reference evidence rather than an equality claim.

Results and limits are recorded here after the MAME run. This reference captures MAME's native device wiring and emulated bus traffic; it does not establish equality with the MiSTer RTL without a separate trace comparison.
